# ChatGPT、Codex、Claude Code、Cursor：初學者怎麼選起步方式？

如果你還在想網站要解決什麼問題，可以先用對話整理需求。當你已有專案檔案，並希望 AI 在指定範圍內修改及驗證，就可以考慮開發代理。以下比較的是使用入口與工作方式。

| 工具 | 適合的起步方式 | 開始前確認 |
| --- | --- | --- |
| ChatGPT | 在對話中把想法整理成頁面需求、文字草稿或驗收清單。 | 確認你目前使用的介面與可提供的資料。[OpenAI Academy：Using ChatGPT](https://openai.com/academy/using-chatgpt/) |
| Codex | 選擇桌面、終端機、編輯器擴充功能或網頁入口，交付一項可驗證的程式任務。 | 官方說明可用 ChatGPT 帳號登入，使用方式與限額依入口、方案及工作區而異。[SRC-0022、SRC-0023] |
| Claude Code | 在終端機或支援的編輯器等入口，請它理解專案、修改相關檔案或執行驗證指令。 | 先指定資料夾與操作範圍，再審閱變更和執行結果。[SRC-0004] |
| Cursor | 在具 AI 協作功能的編輯器中閱讀專案、規劃修改並檢視變更。 | 確認選用的 Agent 模式與權限，再檢查改動的檔案。[SRC-0024] |

## 用同一個小任務試選工具

假設你想加一張活動卡片。若還沒決定內容，先整理出活動名稱、日期與按鈕行為。若已經有網頁，提供相關檔案和限制，要求先列計畫，再改一個區塊。完成後，比對檔案差異，在瀏覽器檢查活動卡片與按鈕。

這是編者的選擇練習。比較時可以問：操作發生在哪個環境？工具會讀哪些資料？我能否看見改動、測試及未驗證項目？如果其中一項無法確認，先縮小任務範圍。

## 如何理解重疊的功能

同一個 ChatGPT 帳號可以是登入入口，Codex 仍有自己的開發工作流。Claude Code 和 Cursor 也能協助多步驟開發，實際可讀寫與可執行的操作取決於使用介面和權限。比較範圍以 2026-11-06 查閱的官方說明為準。[SRC-0022、SRC-0004、SRC-0024]
